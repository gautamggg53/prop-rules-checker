# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep discussion about the code and
the rules, and don't share other people's private trading or account data.

Report unacceptable behaviour to the maintainer through a private GitHub
message or the contact on the maintainer's GitHub profile. Reports are handled
confidentially.
